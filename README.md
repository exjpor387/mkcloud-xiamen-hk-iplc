## 厦港IPLC 到底是哪条线？

厦港IPLC 是 MKCloud 定义的"福建到香港高防 IPLC" 产品，特指入口走厦门 BGP、出口走香港 BGP，中间经过深圳 T3 级别机房中转。MKCloud 官方知识库给出的端内参考延迟为 1~2ms，这个数值代表的是专线在机房之间的实测值，不等于你从家里宽带到香港业务平台的全程延迟。

和广港IEPL（广州入口）、沪港IPLC（上海入口）相比，厦港IPLC 有两个明显特征：

**默认带 100Gbps DDoS 高防，且高防可定制升级**——套餐页直接附带"QoS 100Gbps"的标识，攻击超过基础阈值可以通过工单申请防护升级。这也是它被划成"高防线"的原因。如果只是日常跨境电商后台和办公，并不需要高防，那么广港IEPL 或沪港IPLC 的价格更友好。

**默认配置全部为独享带宽**——MKCloud 在厦港和泉港两个福建入口的产品上，不提供共享带宽版本，起步就是 4 核 8GB / 200Mbps 独享，套餐只有 200M、500M、1G、2G、5G 五个档位。

因为这些参数都属于 MKCloud 在 2026 年仍持续维护的产品资料，并非历史活动价，所以可以直接拿来做选型参考。

## 厦港IPLC 在 MKCloud 整套产品线里的位置

MKCloud 的香港方向出口目前共有 4 条线路可以从中国大陆入口出发：广港 IEPL、沪港 IPLC、深港 IX、厦港 / 泉港高防 IPLC。这几条线的分工并不重叠：

- **广港IEPL**：华南团队、香港后台操作场景，共享带宽起售 228 元 / 月，1~2ms 端内延迟。
- **沪港IPLC**：上海入口到香港，25~28ms 端内延迟，覆盖最广，可共享也可独享。
- **深港IX**：需要先有 UCloud 等云厂机器作为前置，云厂商网络接入，1~2ms 端内延迟。
- **厦港 / 泉港IPLC**：福建入口，含 100Gbps 高防，全部独享，是目前 MKCloud 香港方向的最贵档位。

5 个厦港IPLC 套餐对应的价格从 6000 元 / 月到 110000 元 / 月，是 MKCloud 香港方向产品里唯一动辄五位数起步的系列。广港 IEPL 同等流量规格起步价只有 228 元 / 月。

如果你的业务落在福建本地、明确有 DDoS 防护要求，厦港几乎没有替代方案；如果只是要一条稳定的香港出口，广港和沪港的性价比更突出。

## 双端独立IP、100Gbps 高防、1~2ms 端内延迟：这几个词的真正含义

MKCloud 几乎所有专线 VPS 都采用"单端双 IP"结构，每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP。入口 IP 用于用户远程连接 VPS，业务程序（例如浏览器、爬虫客户端、API 调用）跑在 VPS 上，访问外部网站时由出口 IP 发起。这一结构有两个直接影响：

- 入口被列入 MKCloud 的省级白名单，需提交国内手机号实名认证才能开通。
- 出口不接收外部连入，因此不能拿这台 VPS 当公开站点或游戏服务端。

**100Gbps 高防** 不是同义于"不会被攻击打挂"。官方资料措辞为"默认含 100Gbps QoS"，意味着大流量 TCP / UDP 攻击会被清洗或压制。具体阈值、清洗范围、保护对象在购买时可以通过工单确认。MKCloud 也明确说明默认无 SLA，海缆故障或跨境段问题中断不可作为包赔依据。

**1~2ms 端内延迟** 是专线在机房之间的测量值。从家里宽带到 VPS 入口、再从 VPS 出口到目标平台，全程延迟往往更高。MKCloud 的知识库文章也提醒"全程测量值"应以实际业务测试为准。

把以上三点放在心里，再去看全套餐对比表，就不会把"高防"当成万能 SLA，也不会把"端内延迟 1~2ms"误读为"全程 1~2ms"。

## 谁适合用厦港IPLC，谁更适合走其他线路

不需要高防，就不要硬上厦港。MKCloud 官方知识库很清楚地把"高防"作为厦港IPLC 的差异化卖点，价格溢价几乎全部来自 DDoS 防护和独享带宽的兜底。如果你的业务没有可观测的攻击压力，赌厦港性价比不高。

下面三种情况最匹配厦港：

- **福建本地团队、需要就近接入**：厦门、泉州、福州等地的运营团队，本地宽带到厦门 BGP 入口的连接质量通常优于到广州或上海入口。
- **跨境多账号 + 历史曾受大流量攻击**：高防套餐的防护阈值与清洗能力是核心需求，厦港是 MKCloud 香港方向目前唯一的高端高防档位。
- **持续稳定速率优先、不接受共享峰值波动**：独享带宽下，200M 套餐就在大部分时段稳定跑满 200Mbps，不存在共享峰值人数多时被挤压的情况。

下面三种情况更适合其他线路：

- **预算敏感、且当前无攻击史**：广港 IEPL 共享入门 228 元 / 月起，1TB 月流量 358 元 / 月；沪港 IPLC 共享入门 288 元 / 月。
- **已有云厂服务器作为前置**：深港 IX（1~2ms 端内延迟）会更便宜，前置云费另算。深港IX 1TB 月付 166 元 / 月起。
- **日本或美国出口方向**：沪日 IPLC 25~28ms 端内延迟、沪美 124~134ms 端内延迟，对应方向比香港出口更直接。

选线前最稳的是先估算一个月真实流量和并发数，再按 MKCloud 通行价格表确定档位。MKCloud 在《跨境专线多少钱》里给到的参考点是"200Mbps 与 5Mbps 对应不同计费资源，短时间上传更看重峰值，长时间传输更看重持续速率与额度"——同样适用于厦港IPLC 的独享套餐。

## 购买前必须确认的三件事

### 方式一：实名认证是硬门槛

MKCloud 全线产品需要国内手机号实名认证，IPLC / IEPL 类产品还要配合省级白名单（部分套餐绑定特定省份）。个人需要手机号码 + 姓名 + 身份证号，企业需要营业执照 + 法人身份证 + 对公账户。这与厦门、福建本地的合规要求一致，并不是 MKCloud 自己单独加的限制。

### 方式二：默认无 SLA，海缆故障不赔付

MKCloud 知识库多篇文章里都明确写到"默认无 SLA"。需要书面保障需要单独通过工单询价定制。这一点适合金融量化、游戏出海等对中断敏感的团队提前沟通，而不是下单后再要求补偿。

### 方式三：套餐升降级要工单

开通后想从 500M 升到 1G、从 1G 降回 200M，都需要提交工单处理；降至更低价格套餐时差价不退，迁移与否以工单处理结果为准。这也是 MKCloud 区别于自助云厂商的一个特点。

退款政策方面，MKCloud 仅在质量问题情况下支持退款，需要工单里提交测试截图和具体问题，平台审核判断；不支持开通后变地域。

## 常见问题

**厦港IPLC 和泉港IPLC 有什么区别？**

两条线都属于 MKCloud 福建入口的高防 IPLC，端内延迟都标 1~2ms。区别在于入口位置不同：厦港走厦门 BGP，泉港走泉州电信。按本地到入口的实际宽带测试来选，而不是只看名字。

**出口 IP 是原生 IP 吗？**

MKCloud 资料明确表示"当前资料为服务器 IP，不保证原生、住宅或流媒体解锁属性"。不能为"流媒体解锁 / 原生 IP"这类未承诺属性下单。

**IP 独享能不能保证跨境账号不被关联？**

不能。MKCloud 知识库反复强调 IP 独享只代表资源使用方式，不保证 IP 历史、平台认可或账号不被限制。实际风险仍要通过平台规则判断 + 浏览器隔离 + 操作行为管理共同控制。

**可以拿来做香港方向的公开网站吗？**

不可以。MKCloud 出口 VPS 不支持外部连入，本产品的出口只能用作"在 VPS 上向外访问"。公开站点、支付回调、对外游戏服需要另选支持入站的产品。

**能不能先买 200M 试用一个月，再决定是否升档？**

可以。MKCloud 套餐均支持月付开通。按工单处理升降级即可，但降级差价不退，迁移需以工单为准。

如果你确有福建本地团队持续需要稳定的香港出口、且面对的攻击压力是真实存在的，厦港IPLC 在 MKCloud 产品线里依然是最匹配的选择。如果只是日常后台 + 没有高防需求，把预算留在广港IEPL 或沪港IPLC 上是更合理的决定。先拿真实业务在 200M 档跑一个月，再决定是不是升 500M 或 1G，是 MKCloud 自己也在《跨境专线多少钱》中建议的方式。
